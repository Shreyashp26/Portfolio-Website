A modern, responsive personal portfolio website showcasing my journey across **Artificial Intelligence, Machine Learning, Data, and Software Engineering**.

🌐 **Live Website:**  
https://shreyash-portfolio-website.vercel.app/

## 👋 About Me

I'm **Shreyash Patil**, an MSc in Computing graduate specialising in **Artificial Intelligence** from **Dublin City University**.
